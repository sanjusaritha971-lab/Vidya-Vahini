# Vidya-Vahini 🚍

Vidya-Vahini is an Android application designed to help rural students track their daily transport in real time.

## Features
- Live bus tracking
- Crowdsourced bus ping system
- Breakdown reporting
- Safe-reach notification
- Route-based transport updates
- ETA estimation

## Technologies Used
- Kotlin
- Jetpack Compose
- Firebase Realtime Database
- Android Studio
- Material 3
- GitHub

## Problem Solved
Students in rural areas often face transport delays and uncertainty. Vidya-Vahini helps students receive real-time transport updates and improves safety.
